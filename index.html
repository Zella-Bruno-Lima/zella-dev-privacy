ZZELLA DEV

Política de privacidade

O ZELLA DEV é uma ferramenta interna para acompanhar tarefas, disponibilidade e alocação do time de desenvolvimento a partir de dados do Jira Cloud.

Última atualização: 5 de outubro de 2026

1. Dados utilizados

  • Identificação: nome e identificador da conta Atlassian para autenticar e verificar o acesso ao sistema.
  • Dados do Jira: nomes, identificadores, avatares e situação das contas; projetos, resumos de tarefas, responsáveis, status, datas e histórico de transições.
  • Gestão do time: membros autorizados, alocações manuais, observações e registros de quem realizou alterações administrativas e quando.

2. Finalidade e acesso

Esses dados permitem controlar o acesso, apresentar os painéis de trabalho, acompanhar tarefas e registrar a gestão do time.

Os membros autorizados consultam uma base compartilhada, sincronizada pela conta técnica configurada na integração com o Jira. As permissões individuais de cada usuário no Jira não são reaplicadas aos painéis do ZELLA DEV.

3. Login e armazenamento no navegador

O login ocorre na Atlassian por OAuth 2.0. O ZELLA DEV não solicita nem armazena sua senha Atlassian. O token recebido nesse login é utilizado para identificar a conta e não é salvo na sessão.

O sistema utiliza cookies para manter a sessão e proteger operações contra solicitações indevidas. A preferência de tema claro ou escuro é armazenada localmente no navegador.

4. Armazenamento e retenção

Os dados sincronizados e os registros administrativos ficam no banco de dados da aplicação. A integração se comunica com a Atlassian para autenticação e consulta dos dados do Jira.

A sincronização atualiza a base e remove tarefas e projetos que deixaram de fazer parte do conjunto sincronizado. Não há um prazo automático de exclusão por idade para os cadastros de usuários e registros administrativos; a remoção desses dados depende da administração do sistema.

Sair da conta encerra a sessão, mas não exclui os dados sincronizados do banco.

5. Contato e solicitações

A operação do sistema é conduzida pela equipe responsável pelo ZELLA DEV. Para esclarecer o uso dos seus dados ou solicitar acesso, correção ou exclusão, procure o administrador que disponibilizou seu acesso, pelo canal interno utilizado pelo time.

Alterações nos dados de origem também podem precisar ser feitas no Jira para que sejam refletidas nas próximas sincronizações.
