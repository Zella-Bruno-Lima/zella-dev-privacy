# Privacidade — ZELLA DEV

Página estática com a identidade visual do projeto, sem backend ou dependências de instalação. As fontes são locais e todos os caminhos são relativos para funcionar no GitHub Pages.

O texto descreve a implementação atual: login Atlassian, snapshot compartilhado do Jira, cookies de sessão e proteção, preferência de tema, registros administrativos e retenção sem prazo automático por idade.

## Publicação no GitHub Pages

Publique apenas o conteúdo desta pasta em um repositório público separado, como `zella-dev-privacy`.

Em **Settings → Pages**, selecione **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.

Quando a página estiver disponível, use sua URL HTTPS em **Privacy policy URL** no formulário de distribuição da integração Atlassian. Esse endereço não substitui o callback OAuth do ZELLA DEV.

## Manutenção

Atualize `index.html` quando mudar o tratamento de dados. O contato indicado é o administrador pelo canal interno do time; substitua esse trecho por um contato público específico quando ele estiver definido. A identificação formal da empresa e sua regra de retenção devem ser incorporadas quando fornecidas pelo responsável.
